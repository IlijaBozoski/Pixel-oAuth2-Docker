# Pixel-Registration Tracking

Pixel is an authorization and authentication API that uses Laravel Passport to provide an OAuth2 server implementation.


## Installation

Before you begin, make sure you have Docker installed to run all the required containers.

Open terminal.

Navigate to the directory where this project is stored:

```bash
cd YourDirectory
```
Then you start all the containers by running
```bash
docker-compose up -d
```
You are up and running
## Usage
This API can be tested using tools like Postman, which facilitate making POST requests. The primary purpose of this API is to handle user registration, login, logout, and show their pixel registrations. You can use the data returned for various application needs.
